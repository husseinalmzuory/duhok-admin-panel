# لوحة إدارة دليل دهوك — النسخة النهائية

لوحة ويب مستقلة لإدارة محتوى تطبيق دليل دهوك عبر Supabase، بدون وضع Service Role في المتصفح.

## ما تحتويه
- عرض وبحث وفلترة وفرز جميع الأماكن.
- إحصاءات: الإجمالي، النشط، المخفي، الإحداثيات المؤكدة، والنتائج المعروضة.
- إضافة/تعديل/نسخ/حذف مكان.
- تحديد جماعي مع تفعيل/إخفاء/حذف/تصدير CSV.
- أسماء وأوصاف بثلاث لغات.
- المحافظة ← القضاء ← الناحية من قاعدة Supabase نفسها.
- اختيار الإحداثيات بالنقر على خريطة OpenStreetMap، أو استخدام موقع الجهاز، أو فتحها في Google Maps.
- صورة غلاف + معرض صور، رفع/حذف/تعيين غلاف/ترتيب.
- رفع الصور إلى bucket `place-images` بحد 5MB وJPEG/PNG/WebP.
- إدارة المحافظات والأقضية والنواحي مع حماية حذف العناصر المرتبطة.
- نسخة احتياطية JSON للبيانات السياحية والإدارية والصور (لا تشمل بيانات المستخدمين الخاصة).
- مسح مفتاح الإدارة من الجهاز عند الحاجة.
- تنبيه عند محاولة إغلاق نموذج فيه تغييرات غير محفوظة.

## بعد استبدال هذه النسخة
1. افتح Supabase > SQL Editor وشغّل `setup_final.sql` مرة واحدة.
2. من PowerShell داخل مجلد المشروع شغّل:
   `npx supabase functions deploy admin-api --no-verify-jwt`
3. لا تحتاج إلى تغيير DUHOK_ADMIN_SECRET إذا كان مضبوطًا سابقًا.
4. للتجربة المحلية:
   `npx serve . -l 4174`
   ثم افتح الرابط الذي يظهر تحت Local.

## الأمان
- لا يوجد `service_role` داخل HTML/JS.
- العمليات الحساسة تمر عبر Edge Function.
- الصفحة تستخدم مفتاح إدارة مشترك محفوظ محليًا في المتصفح.
- لا تمنح هذه الملفات صلاحيات CRUD إلى `anon`.
- رابط الموقع وحده ليس وسيلة حماية؛ مفتاح الإدارة هو طبقة الحماية الحالية.

## ملاحظات
- خريطة محرر الإحداثيات تستخدم OpenStreetMap/Leaflet ولا تغيّر شيئًا في خرائط تطبيق Flutter.
- حذف المكان يحذف أيضًا صور المكان من Storage وسجلات الصور/التقييمات/المفضلة المرتبطة لتجنب مشاكل المفاتيح الخارجية.
- حذف قضاء/ناحية/محافظة مرتبط بها بيانات يُرفض بدل كسر العلاقات.
